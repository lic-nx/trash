# Quick Start Guide

## 5-Minute Setup

### 1. Install Dependencies (2 minutes)
```powershell
npm run install:all
```

### 2. Start Development Server (1 minute)
```powershell
npm run dev
```

### 3. Open in Browser (30 seconds)
Navigate to http://localhost:3000

### 4. Create Your First Document (30 seconds)
1. Click "New Document" in the sidebar
2. Enter a title
3. Start typing

### 5. Try Key Features (2 minutes)

**Slash Commands:**
- Type `/` to see all block types
- Select headings, lists, code, tables, etc.

**Live Tables:**
- Click "Tables" button in toolbar
- Select "Tasks" table
- Try Kanban, Calendar, and Gantt views

**AI Assistant:**
- Click "AI" button
- Use quick action "Create task list"
- Insert generated content

**Keyboard Shortcuts:**
- `Enter` - New block
- `Backspace` - Delete empty block
- `↑/↓` - Navigate between blocks
- `/` - Open block menu
